# تشغيل Sniper‑Tn مجانًا عبر Google Apps Script

هذه النسخة تستبدل n8n في إرسال المحتوى إلى Telegram ومراجعته. تعمل ضمن الحدود المجانية لحساب Google ولا تحتاج إلى سيرفر دائم.

## ما تفعله

- ترسل الفيديو التالي قرابة الساعة 16:00 بتوقيت تونس.
- ترسل نص Facebook والوسوم والتعليق المثبّت.
- تعرض زري **اعتماد** و**طلب تعديل**.
- تسمح لشخص واحد فقط باتخاذ القرار.
- تحفظ ترتيب الطابور في Script Properties.
- لا تعيد فيديو اليوم الأول بعد انتهاء الأسبوع؛ تتوقف وتطلب إضافة أسبوع جديد.
- توفر أوامر `/next` و`/status` و`/help` داخل Telegram.

## الملفات

- [`Code.gs`](Code.gs): الكود الذي يُلصق في Google Apps Script.
- [`appsscript.json`](appsscript.json): إعداد اختياري للمنطقة الزمنية والصلاحيات.

---

## 1. إنشاء مشروع Apps Script

1. افتح [مشروع Google Apps Script جديد](https://script.google.com/home/projects/create).
2. سجّل الدخول بحساب Google.
3. غيّر اسم المشروع إلى `Sniper-Tn Manager`.
4. في ملف `Code.gs` احذف الكود الافتراضي `myFunction`.
5. افتح ملف [`Code.gs`](Code.gs)، انسخ محتواه كاملًا والصقه في المحرر.
6. اضغط **Save**.

## 2. إضافة القيم السرية

من **Project Settings** (رمز الترس) افتح قسم **Script Properties**، ثم أضف:

| Property | Value |
|---|---|
| `BOT_TOKEN` | الرمز الذي أعطاه BotFather |
| `TELEGRAM_CHAT_ID` | Current chat ID الخاص بك |
| `APPROVER_USER_ID` | Your user ID الخاص بك |

لا تضف مسافات قبل أو بعد القيم. لا ترسل صورة عندما تكون القيم ظاهرة، ولا تضع الـToken داخل `Code.gs`.

## 3. الانتقال من n8n

لا يمكن أن يستعمل البوت Webhook في n8n و`getUpdates` في Apps Script في الوقت نفسه.

1. لا توقف n8n قبل أن يكون الكود والقيم جاهزين.
2. عندما تصبح جاهزًا للاختبار، افتح n8n.
3. من زر **Published** اختر **Unpublish**.
4. ارجع مباشرة إلى Apps Script ونفّذ الإعداد في الخطوة التالية.

## 4. تشغيل الإعداد لأول مرة

1. من قائمة الدوال أعلى المحرر اختر `setupSniperTn`.
2. اضغط **Run**.
3. وافق على صلاحيات Google المطلوبة للحساب.
4. إذا ظهرت صفحة تحذير لأن السكربت غير موثق، اختر **Advanced** ثم افتح المشروع الذي أنشأته أنت، وبعدها **Allow**.
5. الدالة تحذف Webhook القديم، تنشئ Trigger كل دقيقة، وتضبط الطابور ليبدأ من **اليوم الثاني** لأن اليوم الأول اعتُمد في n8n.
6. يجب أن تصلك رسالة في Telegram تؤكد تشغيل المدير المجاني.

## 5. الاختبار

1. من قائمة الدوال اختر `sendNextContentNow`.
2. اضغط **Run**.
3. يجب أن يصلك فيديو اليوم الثاني مع النص الكامل وزري الاعتماد والتعديل.
4. اضغط **اعتماد**.
5. خلال نحو دقيقة يعالج البوت القرار ويرسل نصًا جاهزًا للنسخ إلى Facebook.

## أوامر Telegram

- `/next`: إرسال المحتوى التالي الآن.
- `/status`: حالة الطابور والمحتوى التالي.
- `/help`: عرض التعليمات.

## وظائف الصيانة

- `showSniperStatus`: إرسال حالة الطابور إلى Telegram.
- `stopSniperTn`: إيقاف Trigger المجاني.
- `resetQueueToDay(2)`: إعادة الطابور إلى يوم محدد؛ تُستعمل من المحرر عند الحاجة.
- `testTelegramConnection`: اختبار الرمز والأرقام دون تغيير الطابور.

## ملاحظات

- لا تنشر هذه النسخة تلقائيًا على Facebook؛ بعد الاعتماد ترسل لك الفيديو والنص للنشر اليدوي.
- القرارات في Telegram قد تحتاج حتى دقيقة واحدة للمعالجة بسبب أسلوب polling المجاني.
- إذا انتهى الأسبوع، يتوقف الطابور بدل إعادة الفيديوهات القديمة.
- ملفات الفيديو مستضافة علنًا على GitHub حتى يستطيع Telegram جلبها.
- إذا أردنا ربط Facebook لاحقًا، نضيف Meta API من دون تغيير نظام Telegram الأساسي.
